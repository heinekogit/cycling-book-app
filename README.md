# Cycling Book App

Expo SDK 57 / React Nativeで開発するCycling Bookのモバイルアプリです。

## 開発

```sh
npm install
npx expo start --dev-client
```

## 確認

### 開発用DBで実機テストする場合

`.env.local` の `EXPO_PUBLIC_SUPABASE_URL` と `EXPO_PUBLIC_SUPABASE_ANON_KEY` はWeb版の `.env.development.local` と同じ開発用プロジェクトに設定します。`EXPO_PUBLIC_WEB_URL` は `https://heinekogit.github.io/cycling-book-web-dev` に設定します。開発版ビルドでも接続先が自動で開発用になるわけではありません。

環境を切り替える前に走行記録を終了し、切替後は `npx expo start --dev-client --lan --clear` でMetroを再起動して、iPhoneで開発用アカウントにログインしてください。

Macから離れて実機テストする場合は、iPhoneを接続して次のReleaseビルドをインストールします。画面コードと `.env.local` の開発用接続先がアプリに組み込まれ、Metroなしで起動できます。コードや接続先を変更した後は再ビルドが必要です。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer npx expo run:ios --configuration Release --device <Xcodeに表示されるiPhoneのUDID> --no-bundler
```

走行中の下書き・送信待ち記録はSupabaseの接続先ごとに分離しています。従来の環境情報を持たない記録は端末内に保持しますが、自動復元・自動送信しません。旧記録が必要な場合は元の接続先を確認したうえで別途復旧してください。アプリを削除すると端末内データが失われるため、復旧前に削除しないでください。

```sh
npm run lint
npm run typecheck
npm test
npm run doctor
```

バックグラウンド位置情報を利用するため、実機確認ではExpo GoではなくDevelopment Buildを使用します。

実走中の位置情報はSQLiteへ逐次退避します。GPSタスクが停止した状態でアプリを再起動した場合は、未保存の記録を一時停止状態で復元します。

終了した走行は通信状態にかかわらず端末内の送信待ちキューへ確定し、起動時・前面復帰時・手動操作でSupabaseへ同期します。

保存済みの実走は「履歴」から日付順に確認でき、詳細画面で距離・時間・平均速度・地図上の軌跡を表示します。

画面表示は日本語と英語を切り替えられます。初回は端末の言語から判定し、選択した言語は端末内に保存します。

ログイン後はホーム画面を表示し、「ルートを使って走る」と「ルートなしで走る」へ分岐します。ルート選択・ナビゲーション画面は今後の実装用の入口を用意しています。

「ルートを使って走る」では、既存Web版のマイルートと同じ `routes` データを一覧表示し、詳細画面でルート軌跡・距離・公開状態・種類を確認できます。

ルート詳細から実走画面へ進むと、予定ルートを青、実際の走行軌跡をピンクで重ねて表示します。予定ルートから30mを超えた実走部分は濃い赤で表示します。選択ルートは端末内の記録とSupabaseの `runs.route_id` に引き継ぎます。

ルートの公開・非公開はWeb版と同じ `set_route_publication` RPCを利用します。公開前にホーム地点の500m圏と公開区間をプレビューし、初期設定では圏内の軌跡・写真・マーカーを除外します。ホーム地点が未設定の場合はWeb版プロフィールでの設定が必要です。元の軌跡は `route_private_geometries` から読み込み、実走にも利用します。

この機能にはWeb版のSupabaseマイグレーション（`202610100001_route_markers.sql` まで）の適用が必要です。適用状態はこのリポジトリのローカル検証では確認していません。

実機確認では、ホーム地点を設定した非公開ルートで「公開する」を開き、除外のオン・オフ、全区間が圏内の場合の公開不可、写真・マーカーの非公開、非公開に戻した際の元の軌跡の復元を確認してください。

Web版で保存したマーカー・コメント・写真は、ルート詳細と実走画面の黄土色のマーカーピン（通常写真はオレンジ色）の吹き出しから閲覧できます。コメント欄は地図に重ねて表示され、×または地図の空いている場所をタップすると閉じます。写真は「写真を拡大」ボタンから開きます。マーカーに紐づく写真は同じピンにまとめ、通常のルート写真は撮影位置に表示します。ルート詳細ではマーカー一覧と写真一覧からも開けます。公開対象から除外したスポットは自分のルートでは表示し、閲覧画面に除外状態を表示します。読み込み失敗時には再試行できます。

実機では、Web版でコメントと複数写真を付けたマーカーを保存し、アプリのルート詳細と「このルートで走る」の地図で黄土色のマーカーピン（通常写真はオレンジ色）をタップしてください。コメント、写真の順序、閉じる操作、実走記録の継続を確認します。
